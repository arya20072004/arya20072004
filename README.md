## 🧑‍💻 About Me

I'm Arya Borhade, a B.Tech Computer Science student specializing in **AI & Data Science at MIT-WPU, Pune**.

I build systems where **backend engineering, machine learning, data pipelines, and real-world applications** meet. My work ranges from financial-market infrastructure and ML recommendation systems to computer vision, agriculture, analytics platforms, and production-oriented web applications.

I enjoy the part of engineering that happens after the tutorial ends: designing data flows, dealing with messy inputs, validating models, building APIs, debugging production failures, and making the whole thing actually work. Humanity has somehow decided that this is called "software engineering."

## 🚀 Featured Projects

### 💹 ML-Powered Stock Recommendation System

**Repository:** [`stock-recommendation-system`](https://github.com/arya20072004/stock-recommendation-system)

A production-oriented ML system for generating **BUY / HOLD / SELL recommendations for Nifty 50 stocks**.

**What it includes:**

- XGBoost-based stock classification
- Technical indicators such as RSI, MACD, Bollinger Bands, ATR, VWAP and OBV
- Sector momentum features built from the Nifty 500 universe
- NIFTY/BANKNIFTY options Put-Call Ratio data
- FII/DII institutional activity
- News sentiment integration
- Confidence-tiered predictions
- Historical backtesting engine
- MongoDB persistence for market and derived datasets
- Flask backend and React/Vite frontend
- Portfolio-level signal visualization
- Automated data collection and model-training pipeline

This project has also involved deeper production concerns such as **historical-data persistence, model identity, evaluation gates, settlement state, pipeline stability, and reproducibility**, rather than stopping at "the model got 94% accuracy on a notebook."

### 🌱 Crop Disease Detection & Monitoring

**Repository:** [`crop-disease-detection`](https://github.com/arya20072004/crop-disease-detection)

An end-to-end agricultural AI system combining computer vision, time-series modelling, APIs, dashboards and mobile deployment.

**Architecture:**

- EfficientNet-B4 for 38-class crop disease classification
- PlantVillage + PlantDoc datasets for domain adaptation
- Confidence gating for inference
- Grad-CAM explainability
- LSTM-based weather/yield modelling
- CNN + LSTM fusion model
- FastAPI inference API
- Streamlit dashboard
- Flutter mobile application
- ONNX model export for cross-platform deployment

The project moves beyond image classification into a broader **crop + disease + weather intelligence pipeline**.
